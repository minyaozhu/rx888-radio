Keys, a macro pad or a dial that sends keys control the radio from any tab. Click Assign, then press the dial button (or turn the knob) you want for that action. Plain-letter keys are ignored while you type in a text box.

A plain scroll-wheel binding takes over scrolling on every page; give it a modifier (e.g. set the dial to send Ctrl + wheel) or use keys instead.
